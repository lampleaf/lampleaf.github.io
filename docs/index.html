Nuovo nome prima si chiamava LumiShelf

Lampleaf Reader

La tua libreria sul telefono: PDF, EPUB, manga e documenti, letti e organizzati in un unico posto.

Scarica la 1.19.5 Come si installa

File APK di 68 MB per Android 8.0 o successivo, pubblicato il 17 ottobre 2026. Nessun account, nessuna pubblicità: i file restano sul telefono.

Cosa fa Lampleaf Reader

Legge

Lettore PDF con indice e ricerca, lettore EPUB impaginato come un e-reader, lettore di manga e fumetti CBZ, CBR e CB7 a pagina singola, doppia o Webtoon.

Organizza

Copertine vere, raccolte, serie manga, metadati, ricerca con filtri. Rinomina senza perdere progressi e segnalibri.

Modifica

Editor PDF (annotazioni, pagine, OCR, firma), fogli di calcolo Excel, documenti Word DOCX e file di testo.

Resta tuo

Gratis, senza pubblicità, senza account e senza server di Lampleaf. Backup in un file che scegli tu, scambio tra dispositivi sulla rete di casa.

Installa e aggiorna

Lampleaf Reader non è sul Play Store: si installa dal file APK pubblicato qui.

  1. Scarica il file dal telefono

    Tocca Scarica la 1.19.5. Il file si chiama Lampleaf_Reader_1.19.5.apk.

  2. Consenti l’installazione

    Aprendo il file, Android chiede di permettere al browser di installare app. Puoi consentirlo solo per questa volta e toglierlo dopo da Impostazioni › App.

  3. Installa o aggiorna

    Tocca Installa, oppure Aggiorna se hai già Lampleaf o LumiShelf. La nuova versione si installa sopra la precedente: libreria, progressi e raccolte restano. Play Protect può proporre un controllo dell’app: succede con le app installate fuori dal Play Store.

  4. Le prossime volte

    In Lampleaf apri Impostazioni › Informazioni › Controlla aggiornamenti, oppure attiva «Avvisami delle nuove versioni».
